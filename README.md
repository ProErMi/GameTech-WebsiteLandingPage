
# GameTech - Website Landing Page

Ini adalah sebuah projek ngoding sederhana membuat website landing page dengan menggunakan HTML, CSS, dan framework CSS, Bootstrap.

Terdapat 3 file yang digunakan untuk membuat website landing page yaitu index.html, style.css, serta file img yang berisi foto-foto.
